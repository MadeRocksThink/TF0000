# Product glossary

- **Project:** A user-owned workspace grouping conversations, memories, packs, and task state.
- **Conversation:** A provider-independent record of one external AI chat.
- **Message:** One ordered speaker turn captured from a conversation.
- **Fragment:** An exact, immutable selection from a message with source offsets where available.
- **Memory:** A durable context item whose meaning, authority, status, and current version are explicit.
- **Memory Version:** An immutable snapshot created by a create, add, merge, replace, supersede, or restore operation.
- **Memory Space:** A named, optionally nested organizer. One memory may belong to several spaces.
- **Context Pack:** A reusable, ordered bundle of memories, fragments, files, requirements, and questions.
- **Scope:** Where context is eligible: global, project, conversation, or task.
- **Attachment:** A binding that makes context available to a conversation for a defined lifetime.
- **Branch:** An alternative context history that may be promoted, merged, or abandoned.
- **Source:** The preserved origin of a memory version: conversation, message, fragment, file, or manual entry.
