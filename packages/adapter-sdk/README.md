# @tf0000/adapter-sdk

Stable MIT-licensed adapter API for TF0000 browser integrations. Adapters normalize visible conversations, selections, and composer operations without sending messages.

Use `defineAdapter` for a validated manifest and `verifyAdapterFixture` in a network-free fixture test. API version `1.0` is backwards-compatible within the 1.x package line; additions are optional and breaking changes require a new API version.
